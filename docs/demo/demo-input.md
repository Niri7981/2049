# D1-02 Demo Input

## 标准 Demo 输入

> 使用专业市场数据分析一下 SOL 当前的市场情况。

这是 V0 演示、端到端测试和录屏时统一使用的标准输入。

## 系统必须如何理解

系统应从这句话中识别出：

- 用户目标：获得一份 SOL 市场分析。
- 分析对象：SOL。
- 所需外部能力：加密资产市场数据。
- Capability：`crypto.market.snapshot`。
- 为什么需要外部能力：仅凭模型已有知识不能可靠回答“当前”市场情况。
- 下一步：查询 Resource Registry，寻找能够提供 SOL 市场快照的 Tool。

## 这句话不代表什么

- 不代表用户已经授权任意金额的付款。
- 不允许 Agent 根据 Prompt 自行决定收款地址。
- 不允许 Agent 调用任意外部 URL。
- 不要求实时交易、下单或提供投资建议。
- 不要求支持 BTC、ETH 或其他资产。

## 输入阶段的预期结果

处理完该输入后，Agent 应先产生以下业务结论：

> 完成这个任务需要一份带时间戳的 SOL 市场数据快照，因此需要寻找 `crypto.market.snapshot` 能力。

此阶段不应该付款，也不应该生成最终市场分析。

## 验收标准

D1-02 只有在以下条件全部满足时才算完成：

- 标准 Demo 输入只有一个版本。
- 分析对象被固定为 SOL。
- 所需能力被固定为 `crypto.market.snapshot`。
- Agent 能解释为什么需要外部数据。
- 输入本身不被视为支付授权。
- 输入阶段不会触发 Wallet 或直接付款。
